<h2 id="about">About me</h2>

<img align="right" width="34%" src="./assets/Computer%20with%20terminal.svg" alt="Developer at work" />

I'm **Joram Tagny**, a full-stack engineer from **Yaoundé, Cameroon** with **4+ years** of shipping production software for banks, health companies, energy firms and startups across **Africa, Europe and the Middle East**.

Most of what I know came from real work: migrating a legacy airline ticketing platform to **Next.js**, writing a **PEG parser** for airline e-ticket formats, tuning **Salesforce LWC** for **TotalEnergies**, folding a four-service **Java/Spring** stack into a single **Go** service, and taking a production API from **21.5 s to 3 s p95**.

I care about code the next person can read, test and extend without needing to call me.

**Right now I'm:**

- Building **Go & Node.js backends** at **Kimia Technologies**: telemetry, insurance and bank security products
- Shipping full-stack features on **AuditPal**, an enterprise **banking audit** platform
- Building a **geo-referenced partnership platform** for **CAP-CUE** (Cameroon–EU cooperation)
- Building **Bliqo**, social-commerce storefronts in **Rust + React**
- Going deeper on **Go, Rust and cloud infrastructure**
